ไม่ต้องแก้โค้ดเลย

ถ้ายังไม่มีไฟล์ไหน หน้าเว็บก็ยังใช้งานได้ปกติ — ช่องนั้นจะเป็นพื้นส้มอ่อน
รอไว้แทน ไม่พังและไม่มีรูปแตก

แก้ที่ตัวแปร `IMG` บนหัวไฟล์ `src/app/page.tsx` ได้เลย เปลี่ยนที่เดียวจบ

## ข้อควรระวัง

- `hero-hamster.png` ควรเป็น **PNG พื้นใส** เพราะวางลอยบนพื้นหลัง
  ไม่มีกรอบครอบ ถ้าใช้ JPG จะเห็นเป็นสี่เหลี่ยมทึบ
- `course-1.jpg` / `course-2.jpg` มีป้าย "แนะนำ" สีส้มทับอยู่มุมซ้ายบน
  เลี่ยงรูปที่มีรายละเอียดสำคัญตรงมุมนั้น
