# รูปภาพของหน้าหลังชำระเงิน

วางไฟล์รูปในโฟลเดอร์นี้ **ตามชื่อด้านล่างเป๊ะ ๆ** แล้วรูปจะขึ้นเองทันที
ไม่ต้องแก้โค้ดเลย

ถ้ายังไม่มีไฟล์ไหน หน้าเว็บก็ยังใช้งานได้ปกติ — ช่องนั้นจะเป็นพื้นส้มอ่อน
รอไว้แทน ไม่พังและไม่มีรูปแตก

| ชื่อไฟล์ | ใช้ตรงไหน | ขนาดที่แนะนำ |
|---|---|---|
| `hero-bg.jpg` | ฉากหลังใหญ่ด้านบน (อยู่หลัง THANK YOU!) | 1920 × 1100 |
| `hero-hamster.png` | แฮมสเตอร์ ด้านขวาของ THANK YOU! | 900 × 760 — **PNG พื้นใส** |
| `course-main.jpg` | ภาพคอร์สที่ลูกค้าเพิ่งซื้อ | 840 × 620 |
| `course-1.jpg` | คอร์สขายต่อ ใบที่ 1 (Procreate) | 560 × 340 |
| `course-2.jpg` | คอร์สขายต่อ ใบที่ 2 (ถ่ายภาพ) | 560 × 340 |
| `course-3.jpg` | คอร์สขายต่อ ใบที่ 3 (จัดองค์ประกอบภาพ) | 560 × 340 |

## อยากเปลี่ยนชื่อไฟล์?

แก้ที่ตัวแปร `IMG` บนหัวไฟล์ `src/app/page.tsx` เปลี่ยนที่เดียวจบ

## ข้อควรระวังตอนเลือกรูป

- `hero-hamster.png` ควรเป็น **PNG พื้นใส** เพราะวางลอยบนพื้นหลัง
  ไม่มีกรอบครอบ ถ้าใช้ JPG จะเห็นเป็นสี่เหลี่ยมทึบ
- `hero-bg.jpg` มีตัวหนังสือดำทับอยู่ครึ่งซ้าย มีเลเยอร์ขาวนวลคลุมไว้ให้แล้ว
  แต่เลือกรูปที่ครึ่งซ้ายไม่รกจะอ่านง่ายที่สุด ขอบล่างระบบไล่จางเข้าหาสีพื้นให้เอง
- `course-*.jpg` มีกรอบมุมสีส้มทับที่มุมบนซ้ายและล่างขวา เลี่ยงรูปที่มี
  รายละเอียดสำคัญตรงสองมุมนั้น

# ข้อมูลที่ต้องต่อกับหลังบ้าน

ตอนนี้ข้อมูลคำสั่งซื้อเป็น**ค่าตัวอย่าง** อยู่ในตัวแปร `ORDER`
บนหัวไฟล์ `src/app/page.tsx` ของจริงต้องดึงมาจากระบบหลังบ้าน:

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | เลขคำสั่งซื้อ (ผู้ใช้กดคัดลอกได้ และใช้อ้างอิงตอนติดต่อทีมงาน) |
| `date` | วันที่ชำระเงิน |
| `email` | อีเมลที่ส่งใบยืนยันไป |
| `method` | ช่องทางชำระเงิน |
| `course` | ชื่อคอร์สที่ซื้อ |
| `level` | ระดับของคอร์ส |
| `price` | ยอดที่ชำระ (ตัวเลขล้วน ไม่ต้องใส่คอมมา) |

ส่วน `EVENTS` (กิจกรรม) และ `UPSELL` (คอร์สขายต่อ) ก็อยู่ไฟล์เดียวกัน
แก้ได้ตรง ๆ หรือจะต่อ API ทีหลังก็ได้

**เรื่องวันที่ของกิจกรรม:** ฟิลด์ `startUtc` / `endUtc` ต้องเป็นเวลา **UTC**
เพราะใช้สร้างไฟล์ปฏิทิน (.ics) เวลาไทยคือ UTC+7 เช่น 19:30 น. ไทย
= `20260815T123000Z` ถ้าใส่เวลาไทยตรง ๆ ปฏิทินจะเพี้ยนไป 7 ชั่วโมง
